# Adaptive Task Router · AFD 2.0 完整版

这是一个可独立阅读、审查和安装的 Codex 多代理协作插件。解压后即是完整插件源码，不需要其他版本、差异补丁或 AFD 业务仓库。

当前版本：`0.2.0+afd2.sol61.20261009.2`。当前状态：完整源码候选，等待 Pro 审查；尚未在 AFD 2.0 正式启用。

## 从哪里开始

- **审查**：直接阅读 [给 Pro 的审查说明](PRO_REVIEW.md)，然后检查两个技能及其参考。
- **使用**：阅读 [使用指南](docs/USAGE.md)。执行技能需要明确启用，建议技能只提出建议。
- **安装**：阅读 [安装指南](docs/INSTALLATION.md)，使用本包完整源码。
- **验证**：阅读 [本版核验记录](docs/VALIDATION.md)和[行为场景](tests/SCENARIOS.md)。

## 能做什么

一次明确启用后，在当前对话中持续判断任务目标、难度、依赖与验收，按需选择模型和推理档位，并协调原生子代理。简单任务直接完成，复杂任务可分配实施、调查、整合与独立复核。

完整保留动态选型、实施型帮手、递归委派、全树共享容量、资源修改权、输入版本失效、失败诊断、停止传播和恢复检查。子代理模型包括 `gpt-6-astra`、`gpt-6.1-sol`、`gpt-6-luna`，参考表覆盖 17 个模型与档位组合；实际可用范围由当前宿主工具决定。

## 两个入口

| 技能 | 使用方式 | 职责 |
| --- | --- | --- |
| [route-task](skills/route-task/SKILL.md) | 明确调用后，在当前对话持续使用 | 分析、选型、原生委派、协调与验收 |
| [suggest-task-routing](skills/suggest-task-routing/SKILL.md) | 允许自动发现，但只建议 | 判断分工是否有实质收益，等待用户接受 |

首次启用示例：

```text
请使用 $adaptive-task-router:route-task 完成以下任务：……
在当前对话后续请求中持续按需选型、分工与验收。
```

之后可以直接继续任务。“这次不用”仅影响当前请求；“关闭”持续停用；“先停止”暂停工作，收到继续指令后才恢复。仅讨论插件或引用别人的启用语句不会启动执行。

## 使用边界

插件使用宿主原生能力，不包含运行服务、API key、MCP、Apps 或 hooks。主线程模型由用户和宿主决定，插件不热切换主线程或修改全局模型、权限和容量。协作规则不增加业务、生产、发布或正式调度授权；实际权限和资源隔离仍由宿主与项目负责。

规则中的容量、停止传播和单一修改负责人需要执行者遵守，并非新增的强制安全隔离。没有原生子代理工具时，可以在已授权范围内由当前代理继续，不自行改走外部付费服务。

当前尚无本版真实多代理效果、成本或耗时对照，不宣称性能提升。原生接口参数以当次工具 schema 为准；参考中的带日期接口观察需结合现场核对。
