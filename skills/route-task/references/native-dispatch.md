# 原生接口与配置证据

准备实际分派时读取。实际工具 schema、调用反馈和宿主规则优先；本文件不创造工具或权限。不同 Codex 版本与宿主的参数可能不同，不把某次环境观察写成通用限制。

## 首次核对，变化后再核对

只核对本任务所需能力：原生创建／继续／等待／状态／停止入口，支持的模型与档位，角色选择、上下文继承、容量计数及释放条件。记录宿主版本或可取得的版本信息、核对时间和来源；字段未提供就写未知。已有证据仍有效时复用，不每轮联网或扫描配置。

若 schema 支持 `model`、`reasoning_effort`，分派时显式提供；不支持时不硬塞，也不假称已实现动态切换。用户指定项不可用时仅暂停受影响分派，说明缺口；自动选型只在已授权且受支持的范围调整。权限或必要指定角色缺失时，不以默认角色绕过。

## 上下文与角色

默认优先新建隔离上下文，减少无关历史与审查锚定；宿主支持时可用 `fork_turns: "none"`。全历史 fork 是否接受模型／推理覆盖取决于当次 schema，不再声明一律不支持。采用全历史前检查权限、敏感信息和对独立复核的影响。

需要指定角色且 schema 提供 `agent_type` 或其他原生选择字段时，使用真实角色标识；没有该字段时不得虚构。定向核对角色是否加载、是否覆盖模型／档位／工具设置以及实际生效情况。若角色固定使用本包不允许的 Sol 型号，不向该角色派送；改选符合授权的可用配置或报告缺口。配置文件、任务名称或代理自述都不能证明角色已应用。不要为绕过冲突修改全局配置。

下面只演示一种 schema 支持这些字段时的请求形状，不直接执行、不预授予权限，也不强制所有帮手都是叶子：

```json
{
  "task_name": "bounded_evidence",
  "model": "gpt-6.1-sol",
  "reasoning_effort": "high",
  "fork_turns": "none",
  "message": "在已核实的本次授权内完成指定有界问题。交接包含原始材料入口及版本、允许动作、验收、停止条件和实际分配名额。未授予实施权时仅返回建议；进一步委派仅在明确分配的分支名额和权限内进行。返回原始证据、产物版本、未验证项及后代和工具状态。"
}
```

将占位交接替换为真实最小上下文后才分派；需要角色时仅按现场 schema 增加选择字段。递归遵守[协调协议](recursive-orchestration.md)。

## 继续、等待与停止

同一问题、配置和上下文仍适合时优先原生 follow-up；换模型、改变研究方向或需要独立复核时新建有界代理。不能用提示词让现有代理变成另一模型，换线程也不清零失败或预算。

根代理有独立工作时继续推进；真正需要结果时按宿主支持的事件／批量等待机制等待，采用任务相称的等待方式，不反复极短轮询。等待超时只表示尚未收到结果，不证明创建失败或副作用未发生。

区分已接受、运行中、终态和已释放。核算整树及预留名额，包含宿主实际计数的父节点；不能仅凭等待或收到结果推断槽位释放。中断父代理不一定停止后代，按已知身份逐项确认本任务的代理、进程和待返回调用；未知项保留隔离并披露。

## 证据与能力缺口

记录任务／父节点、输入和验收版本、请求模型／档位／角色、原生身份、状态、产物与验证。只有复杂任务才维护完整清单。

区分建议配置、已提交参数、已接受调用和宿主实际回显。未回显就标记未回显；技术只读隔离与行为只读分别取证。不要把 UI 选项、保存的默认值或代理自述当作实际配置。耗时和用量仅使用工具实际数据，不从共享账户额度差额推算单任务扣费。

缺原生能力时完成当前代理可做的授权工作并说明限制；不创建普通侧栏任务、额外 Codex CLI、外部 API、hooks 或后台服务绕过。核对模型不读取认证文件、Cookie 或秘密。

参考：[官方子代理与角色配置](https://learn.chatgpt.com/docs/agent-configuration/subagents)。2026-10-09 查阅的官方说明确认角色文件可能覆盖模型／推理，且权限继承还受父回合实时设置影响；这不证明任一用户客户端已经加载对应角色。原生字段仍须现场核验。
